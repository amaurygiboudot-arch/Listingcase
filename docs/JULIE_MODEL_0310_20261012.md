# JULIE TEST 0.3.10 — choix du moteur local
12 octobre 2026. Développement expérimental, aucun déploiement public ni frais engagés.
## Réalisation
Le moteur Android était fixé au chemin et à la taille du 1,5B. Il accepte maintenant le 1,5B existant ou un Qwen2.5-3B-Instruct Q4_K_M officiel vérifié.
Réglages → Moteur de conversation : téléchargement sur le téléphone dans le navigateur, import via le sélecteur Android, activation explicite et retour au 1,5B. Le modèle reste séparé de l'APK.
Le 1,5B et toutes les données de conversation sont conservés. Le choix du modèle est enregistré dans des préférences distinctes ; aucune migration de souvenirs.
L'import se fait hors du fil d'interface, avec progression, limite exacte de taille, SHA-256, fichier temporaire puis renommage atomique. Import invalide : aucun modèle installé précédemment n'est remplacé. Un import réussi ne sélectionne pas automatiquement le modèle.
Changement interdit pendant une génération/import ; ancien modèle natif libéré dans la file de travail avant chargement du suivant. Sélection du 3B refusée sous 2,8 Go de RAM disponible (seuil conservateur, pas une garantie contre toute pression mémoire).
RAM totale affichée. Téléchargement + copie nécessitent environ 4,5 Go libres ; copie seule vérifiée avec réserve de 256 Mio. Le fichier téléchargé reste géré par l'utilisateur.

## Vérifications
31 tests Node réussis, zéro échec (dialogue, ADN, examens, stockage).
Test Java réel du composant d'import : fichiers incomplets, mauvais hash et taille excessive refusés en préservant l'ancien fichier ; import valide, progression et nettoyage temporaire vérifiés sur des fixtures locales.
Test Edge isolé avec passerelle Android simulée : 3B indisponible avant vérification, téléchargement/import explicites, boutons bloqués pendant import, libellé actif et retour au 1,5B.
Comparaison réelle des modèles déjà présents dans Ollama PC : détails dans model-3b-results.json. Même prompt applicatif, génération brute, température 0, contexte 2048, plafond 110 jetons. Ce test contourne volontairement les réponses fixes du profil pour comparer les modèles.
Le 3B rejette une exigence d'accord systématique là où le 1,5B l'accepte, mais sa réponse au retour du travail reste maladroite. Aucun gain général de naturel démontré.
Les temps incluent des chargements à froid et de la contention sur le PC. Ils ne prédisent pas les temps Android. Les variantes Ollama peuvent avoir une quantification différente du fichier GGUF proposé au téléphone.
## Limites
Téléphone débranché : aucun test de sélection/import/inférence sur l'appareil réel. Le fichier officiel 3B n'a pas été chargé dans le JNI Android durant cette session.
Le 3B reste expérimental et réversible ; il n'est pas présenté comme le maximum matériel validé ni comme systématiquement meilleur. Pas d'accélération GPU/NPU nouvelle, pas de nouveau réentraînement, pas de mémoire automatique supplémentaire.
La validation Android, la vitesse et l'usage mémoire réels restent à mesurer avant de tenter plus volumineux.
## Installation
Installer JULIE TEST 0.3.10 par-dessus la version TEST, sans désinstaller. Réglages → Moteur de conversation → Télécharger → Importer → Utiliser le 3B. Wi-Fi préférable pour les 2,1 Go.
