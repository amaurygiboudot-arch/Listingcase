# JULIE TEST 0.3.12 — contexte réutilisé et affichage continu

## Objectif
Réduire le travail avant le premier fragment et l'attente entre les mises à jour du texte, en conservant le modèle 3B sélectionné. Aucun nouveau modèle à télécharger.

## Changements
- Le contexte llama est conservé en mémoire entre les réponses, sous le mutex existant.
- Seul le préfixe de tokens strictement identique à celui de la requête précédente est réutilisé. L'ancienne réponse et toute partie divergente sont supprimées du cache avant l'inférence.
- Le dernier token du prompt est toujours recalculé pour obtenir les logits corrects, même pour deux prompts identiques.
- Tout échec réinitialise le contexte. Le changement de modèle et la fermeture libèrent le contexte avant le modèle.
- Chaque token produit peut déclencher l'affichage, au lieu d'un groupe de quatre. Les octets UTF-8 incomplets restent en attente pour éviter les accents ou emojis corrompus.
- Le polling WebView reste à 100 ms. Aucun délai artificiel d'écriture ajouté.
- Version Android 300008 / 0.3.12-3b-fluide-test, version interface 0.3.12.

## Vérifications
- Compilation JNI ARM64 Android 28 réussie contre les en-têtes et bibliothèques llama.cpp installés.
- Test C++ du préfixe: prompt vide, identique, allongé, raccourci, contexte divergent et changement dès le premier token.
- Test C++ de chaque coupure d'octets sur ASCII, accents et emoji.
- Test C++ exécuté avec AddressSanitizer et UndefinedBehaviorSanitizer; fuite mémoire non testée car LeakSanitizer incompatible avec ce conteneur.
- 33 tests Node réussis: conversation, streaming, examens, ADN, conservation et migrations.
- Tests C++ de fonctions auxiliaires et tests Node ne constituent pas une exécution du 3B sur Android.

## Limites et mesure attendue
Le premier appel après ouverture reste un démarrage à froid. La réutilisation profite aux échanges suivants dont le début du contexte est identique. Elle consomme de la RAM persistante jusqu'à fermeture ou changement de moteur.
L'affichage plus fréquent ne signifie pas une hausse du débit de génération du modèle. Aucune accélération chiffrée n'est annoncée: téléphone débranché, pas de mesure matérielle réalisée ici.
Comparer dans Réglages les premiers mots et la durée totale sur plusieurs messages de longueur comparable; séparer le premier échange des suivants.

## Conservation
Aucune modification du stockage des conversations, de l'ADN, des résultats ou des fichiers modèle. Cache de calcul seulement en RAM, sans nouveau fichier contenant les échanges.
Application expérimentale uniquement; document maître et décisions inchangés. Pas de publication ou de déploiement production.
