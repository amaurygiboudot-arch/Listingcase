# Origine du modèle humain de Julie V3

Le projet privé Genesis utilise `web/public/assets/human-realistic.glb` et cite comme source `kunalkushwaha/vsim/packages/assets/library/human.glb` (MakeHuman/MPFB, CC0).

L’APK V3 télécharge **le même fichier source public** à la compilation, sans accéder aux données ni au serveur de Genesis. La morphologie féminine initiale s’inspire des principes du moteur Genesis, mais la version V3 ne reproduit pas encore toutes les transformations de l’Ève du jeu (peau dynamique, morphs complets, historique biologique).

Source : https://github.com/kunalkushwaha/vsim/blob/main/packages/assets/library/human.glb
Guide : https://github.com/kunalkushwaha/vsim/blob/main/docs/guides/blender-characters.md
Licence du modèle généré : CC0 ; vérifier séparément tout futur accessoire ou texture de tiers.

Identité de Julie : JULIE_001. Les données d’Ève et la base Genesis ne sont jamais copiées.
